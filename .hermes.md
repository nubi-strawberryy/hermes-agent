# Hermes fork backup policy

This repository is the public personal backup fork of Hermes Agent. It is not
an upstream contribution target by default.

## Delivery

Read `.github/repo-policy.json` before publishing. The default profile is
`backup-main`: scoped changes may be committed and pushed directly to this
fork's `main`; a PR is optional. Keep `origin` pointed at upstream for
read-only comparison. Never push to upstream from this backup workflow.

Preserve unrelated dirty work, stage only requested paths, run focused tests,
run the secret/path guard, run `git diff --check`, and read back the fork's
`main` SHA after push.

## Content boundary

Publish Hermes source, tests, documentation, and intentionally public workflow
files only. Do not publish `.env` files, auth tokens, `state.db`, session
transcripts, credentials, private keys, or unsanitized runtime state.
